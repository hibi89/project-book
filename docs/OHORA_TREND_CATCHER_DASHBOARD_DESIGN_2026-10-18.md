# 오호라 Trend Catcher 대시보드 설계안
**작성일: 2026년 10월 18일**

## 1. 프로젝트 핵심 방향

**원본 데이터 축적을 기반으로 다양한 트렌드 분석 방식을 제공하고, 담당자가 AI를 활용해 자유롭게 분석할 수 있는 시스템 구축.**

처음부터 개발자가 트렌드를 하나의 기준으로 정의하지 않는다.

원본 데이터를 최대한 확보하고, 다양한 분석 기준을 적용하여 오호라 담당자가 직접 판단하고 활용할 수 있도록 한다.

### 기본 구조
- 데이터 수집: 인스타그램 공식 API + n8n
- 데이터 저장: 데이터베이스(DB)
- 데이터 분석: Python + SQL
- AI 자유 분석: LLM API
- 사용자 화면: 4개 탭으로 구성된 대시보드

---

## 2. 대시보드 4개 탭

### ① 원본 데이터 탐색

**목적: 수집된 데이터를 최대한 가공 없이 확인한다.**

- 공식 목록의 인스타그램 294개 계정
- 게시물 날짜, 캡션, 좋아요, 댓글 등
- 국가별·기간별 필터
- 계정별·게시물별 조회
- 참여도 및 게시물 정렬
- 원본 게시물 확인

원본과 AI가 생성한 분류 정보는 구분하여 저장한다.

### ② 가중치 기반 트렌드 분석

**목적: 다양한 기준으로 트렌드 후보를 발견한다.**

예시 분석 기준:
- 참여율
- 최근 참여도 증가 추세
- 특정 디자인의 등장 빈도
- 여러 계정에서의 동시 등장
- 국가별 디자인 반응 차이

각 지표에 가중치를 설정하여 종합 점수를 계산한다.

분석 알고리즘은 여러 버전으로 관리하고 비교할 수 있도록 한다.

단, 데이터가 충분히 축적되기 전에는 일부 변화 추세 분석이 제한될 수 있다.

**결과는 검증 전까지 '트렌드 확률'이 아닌 '트렌드 후보 점수'로 표현한다.**

### ③ AI 자유 분석

**목적: 담당자가 자연어로 원하는 분석을 직접 요청한다.**

예시 질문:

"최근 3개월 동안 일본에서 갈색 네일의 반응이 다른 색상보다 좋았는지 분석해 줘."

AI가 질문을 해석하고 DB에서 관련 데이터를 조회한다.

이후 Python·SQL로 계산한 결과를 표, 그래프, 설명으로 제공한다.

- 자연어 기반 데이터 조회
- 조건별 비교 분석
- 자유로운 분석 요청
- 결과에 사용된 근거 데이터 확인
- 유용한 분석 조건 저장 기능은 추후 확장

**중요:** AI는 읽기 전용으로 데이터에 접근하며, 외부 AI API로 고객사 데이터를 전송할 때는 사전 승인을 받는다.

### ④ 데이터 수집 관리

**목적: 데이터 수집 시스템의 정상 작동과 데이터 신뢰성을 관리한다.**

- 전체 294개 계정의 수집 상태
- 계정별 수집 성공·실패 여부
- 마지막 수집 성공 시간
- 수집 실패 원인
- API 호출 제한 및 오류
- 중복 데이터 확인
- 재수집 대상 관리
- 누적 수집 현황

현재 검토 중인 계정당 최근 게시물 5개 수집 전략을 적용하고, 이후 신규 게시물을 지속적으로 누적한다.

## 3. 공통 기능

**국가와 기간 필터는 모든 탭에 공통 적용한다.**

국가: 한국 / 미국 / 일본 / 전체

기간: 직접 날짜 선택 및 최근 7일·30일·90일 등

단, 데이터 수집 관리 탭은 게시일뿐 아니라 수집 실행일 기준으로도 조회할 수 있도록 한다.

---

## 4. 데이터 처리 원칙

전체 시스템의 데이터 흐름은 다음과 같다.

**인스타그램 수집 → 원본 DB 저장 → 분석용 데이터 생성 → 대시보드 조회 → AI 자유 분석**

핵심 원칙은 네 가지다.

1. 원본 데이터는 별도로 보존한다.
2. 분석 모델이나 가중치가 변경되어도 원본을 다시 수집하지 않도록 설계한다.
3. 데이터 수집과 대시보드 조회를 분리하여 조회할 때마다 재수집하지 않는다.
4. AI의 추론 결과와 실제 관측된 데이터를 구분한다.

색상이나 디자인 유형처럼 원본 API에서 직접 제공하지 않는 정보는 이미지 분석을 통해 별도로 생성한다.

## 5. 개발 우선순위

| 순서 | 기능 | 우선순위 |
|---|---|---|
| 1 | 데이터 수집 안정화 및 DB 저장 | 최상 |
| 2 | 원본 데이터 탐색 | 최상 |
| 3 | 수집 관리 화면 | 높음 |
| 4 | 가중치 기반 트렌드 분석 | 높음 |
| 5 | AI 자유 분석 | 높음 |
| 6 | 디자인 고도화·추가 기능 | 낮음 |

내부 직원이 사용하는 시스템이므로 화려한 시각 디자인보다 **정확성·조회 편의성·분석 기능**을 우선한다.

### 최종 개발 목표

**① 원본 데이터 탐색 + ② 가중치 기반 트렌드 분석 + ③ AI 자유 분석 + ④ 데이터 수집 관리**

이 네 가지 기능으로 구성된 대시보드를 구현한다.

가장 중요한 차별점은 **트렌드 분석 기준을 개발자가 일방적으로 고정하지 않고, 오호라 담당자가 직접 변경하고 새로운 분석을 시도할 수 있다는 것**이다.

이를 통해 단순 트렌드 순위 제공 도구가 아니라, 향후 분석 기능을 지속적으로 확장할 수 있는 업무용 AI 데이터 플랫폼을 지향한다.

**현재 상태: 설계 구상안. 구현·성능·정확도는 아직 검증되지 않음.**
